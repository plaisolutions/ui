Download chat files without leaving the page, and list a conversation's files.

- Office documents: a result with a single file shows it inline with a download button, without the side sheet. With several files, each row of the sheet has its own download button instead of opening the file in a new tab.
- Downloads fetch the file and save it under its name. If the file host does not allow this origin (CORS), the file opens in a new tab instead; an HTTP error shows "Download failed".
- New `ConversationFilesSheet` (paperclip trigger with a count, or controlled with `open` and `showTrigger={false}`), `ConversationFilesList` and `getConversationFiles(messages)`: the user's uploads and the files generated by office_documents in the loaded messages, each with a download button. Copy in 10 languages.
