Support the `code_execution` tool, the agent that runs code in a sandbox to analyze data and generate files.

- `@plaisolutions/client`: adds `"code_execution"` to `UIToolType`, plus `CodeExecutionToolMetadata` (`status`, `media_files`, `steps`, `steps_omitted`, sandbox usage and `error_details`), `CodeExecutionMediaFile`, `CodeExecutionStep`, `CodeExecutionStepKind`, `CodeExecutionStatus`, `CodeExecutionErrorDetails` and `UICodeExecutionToolCallPart`. The reducer and the history normalizer keep the metadata as the backend sent it.
- `@plaisolutions/react`: adds `ToolResultCodeExecutionCard`, routed from `ToolResultCard` (failed runs too, so the sandbox error is shown). It shows the status (success, partial, error), the generated files with a download button and, when the backend sends them, the executed steps. `ToolUseIndicator` has a "running code" label and `getConversationFiles` includes the files generated by `code_execution`.
